Home Assistant — server-side key

🔒 There is no token field here on purpose. The HA long-lived token lives only on the server — set HA_TOKEN in docker-compose.yml env, or as a Docker secret at /run/secrets/ha_token. It is never sent to, stored in, or typed into the browser. The browser only sends an entity_id + action; this server adds the token when it calls HA.

Checking server key…

To rotate the key: create a new token in HA → Profile → Security, update HA_TOKEN on the server and restart the container. No browser change needed.
